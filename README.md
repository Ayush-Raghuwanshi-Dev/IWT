# IWT Lab Projects

This workspace contains lab tasks and mini-projects for the IWT subject. Each folder is a self-contained project with its own HTML/CSS/JS or backend setup.

## Projects

| Project | Description | How to Run |
| --- | --- | --- |
| Calculator | Modern calculator UI with keyboard support. | Open `Calculator/index.html` |
| CelsiusConverter | Celsius to Fahrenheit converter with validation. | Open `CelsiusConverter/index.html` |
| SILLY_STORY_GENERATOR | Random story generator with name and unit toggles. | Open `SILLY_STORY_GENERATOR/index.html` |
| STUDENT_DETAIL_FORM | Student form that displays details on the same page. | Open `STUDENT_DETAIL_FORM/index.html` |
| portfolio | Simple portfolio site with Home, About, Contact. | Open `portfolio/index.html` |
| AUTH-SYSTEM | Express + MongoDB auth system with JWT access/refresh tokens. | `npm install` then `npm start` |
| csv-graph-app | Upload CSV and generate a graph via Python. | `npm install`, `pip install -r requirements.txt`, `npm start` |

## Notes
- Node projects require Node.js and npm.
- The CSV graph app requires Python and matplotlib.
- The auth system uses MongoDB; configure `.env` before running.
